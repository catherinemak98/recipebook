# Catherine’s Recipe Book

A lightweight, mobile-first personal recipe book.

## What is included
- English / Bahasa Indonesia toggle
- Only one language shown at a time
- Language choice remembered on each device
- Keyword / ingredient search
- Category filters
- Mobile-first recipe cards and cooking view
- Technique checkpoint section for recipes where a visual is useful

## Publish with GitHub Pages
1. Put all files in the root of your GitHub repository.
2. In GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.
6. GitHub will show the public Pages URL after deployment.

## Adding recipes
Add another recipe object to `recipes.js`. Keep both `en` and `id` versions for title, tags, ingredients, method, notes, and visual caption (if used).

## Images
Create an `images` folder when technique images are added. Technique/checkpoint images are preferred over decorative food photos.
